# Changes

## 1.0.0

First release.

- Year-by-year cost of custom software and of an off-the-shelf product: build, hosting and support against setup, licences per seat, price rises, integration and time lost to workarounds.
- The cost of what the business keeps paying for while custom software is being built.
- Present value with a discount rate, break-even year, the user count at which custom costs less.
- Sensitivity: which inputs move the answer most.
- Reports as text, Markdown, CSV and JSON.
- Release packages come with a CycloneDX SBOM, SHA-256 checksums and a build provenance attestation.
